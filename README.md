One-line roast of a smart fridge for make.fun's "Roast the Smart Fridge: One Line, Best Laugh Wins" bounty. Three roast candidates were written and scored against the judge's criteria (on-theme, funny, fresh, tight, specific to the gadget); the winner — the expiry-date snitch that escalates from an email to cc'ing the wife to suggesting a funeral — is written to /output/entry.txt (116 characters, single line).
